# WCAG 2.1 对比度报告

## 测试方法
- 采用 WCAG 2.1 相对亮度公式计算对比度
- 验证关键文本与背景组合的 AA 标准（普通文本 ≥ 4.5:1）

## 结果
| 前景色 | 背景色 | 对比度 | 结论 |
|---|---|---:|---|
| `#1B2A44` | `#FFFFFF` | 14.37:1 | 通过 |
| `#415675` | `#FFFFFF` | 7.47:1 | 通过 |
| `#2F6BFF` | `#FFFFFF` | 4.50:1 | 通过 |
| `#2458D8` | `#FFFFFF` | 6.07:1 | 通过 |
| `#1B2A44` | `#F5F7FB` | 13.40:1 | 通过 |

## 结论
- 本次品牌主文本组合满足 WCAG 2.1 AA 的最小对比度要求
- `#2F6BFF` 用于正文时仅刚好达到阈值，建议正文优先使用 `#2458D8` 或深色文本
