# 我的知识产权平台 V1.0 软件说明书

## 1. 引言

### 1.1 编写目的
本文档旨在为“我的知识产权”平台（以下简称“本平台”）的用户提供详细的操作指南和功能说明。文档涵盖了软件的安装、配置、功能使用及常见问题解答，帮助用户快速上手并高效利用平台资源。

### 1.2 背景
在知识经济时代，知识产权已成为核心竞争力的重要组成部分。为解决传统知识产权运营中存在的信息不对称、匹配效率低、价值评估难等问题，本平台应运而生。平台整合了海量专利数据与专家资源，利用大数据与人工智能技术，实现供需精准匹配与价值科学评估，打通知识产权成果转化的“最后一公里”。

### 1.3 定义
- **专利检索**：基于 Elasticsearch 的高性能全文检索功能。
- **智能匹配**：利用 AI 算法根据需求描述自动推荐相关专利与专家。
- **价值评估**：通过多维度指标体系对专利进行自动化评分与价值估算。

## 2. 软件概述

### 2.1 软件简介
“我的知识产权”是一个集专利检索、管理、评估、交易与咨询于一体的综合性服务平台。采用 B/S 架构，前端基于 Vue 3 + TypeScript 构建，后端采用 Spring Boot 微服务架构，结合 MySQL 与 Redis 数据库，确保系统的高性能与高可用性。

### 2.2 主要功能
1.  **用户中心**：支持注册登录、实名认证、个人资料管理及安全设置。
2.  **专利检索**：提供多条件组合检索、关键词智能补全与结果筛选。
3.  **专利管理**：用户可上传、编辑、维护个人名下的专利资产。
4.  **需求大厅**：发布技术需求，查看系统智能推荐的解决方案。
5.  **专家库**：汇聚各领域专家，支持按专业方向查询与对接。
6.  **价值评估**：输入专利信息，一键生成详细的价值评估报告。
7.  **成果转化**：展示成功转化的案例，提供全流程转化服务支持。
8.  **AI 咨询**：基于大模型的智能助手，解答法律法规与业务疑问。

### 2.3 运行环境
- **浏览器**：Chrome 80+, Firefox 70+, Edge 80+ 及其他现代浏览器。
- **分辨率**：建议 1366x768 及以上，支持移动端响应式访问。
- **网络**：建议宽带接入，网络延迟 < 100ms 以获得最佳体验。

## 3. 安装与访问

### 3.1 访问方式
本平台为 Web 应用，无需安装客户端。用户直接在浏览器地址栏输入平台网址即可访问：
- **正式环境**：`http://your-domain.com`（请替换为实际部署域名）
- **测试环境**：`http://60.205.242.113`

### 3.2 账号注册
1.  点击首页右上角的【注册】按钮。
2.  填写用户名、密码、手机号等必填信息。
3.  阅读并同意《用户服务协议》。
4.  点击【提交注册】，系统提示注册成功后即可登录。

## 4. 功能操作指南

### 4.1 首页概览
首页展示了平台的核心数据统计、热门功能入口及最新动态。
- **数据看板**：实时显示平台收录的专利总数、入驻专家数及累计转化金额。
- **快捷入口**：一键直达“专利检索”、“需求发布”、“找专家”等高频功能。
- **AI 悬浮窗**：右下角常驻 AI 咨询入口，点击即可展开对话面板。

### 4.2 专利检索
1.  **基础检索**：在顶部搜索框输入关键词（如“人工智能”、“新能源”），点击搜索。
2.  **高级筛选**：在结果页左侧栏，可按“专利类型”（发明/实用新型/外观）、“申请年份”、“法律状态”进行过滤。
3.  **查看详情**：点击专利标题，进入详情页查看摘要、权利要求书及法律状态信息。

### 4.3 需求发布与匹配
1.  **发布需求**：
    - 进入【需求大厅】，点击【发布需求】。
    - 填写需求标题、详细描述、所属领域及预算范围。
    - 提交后系统自动审核。
2.  **智能匹配**：
    - 在需求详情页，系统会自动推荐匹配度高的专利与专家。
    - 点击【保存匹配结果】可将推荐列表收藏至个人中心。

### 4.4 专家库查询
1.  点击导航栏【专家库】。
2.  支持按姓名、研究方向或所属机构搜索。
3.  点击专家卡片，查看其发表论文、授权专利及过往合作案例。

### 4.5 专利价值评估
1.  进入【价值评估】模块。
2.  输入目标专利号或上传专利文件。
3.  选择评估模型（如“市场法”、“收益法”）。
4.  点击【开始评估】，稍等片刻即可下载生成的 PDF 评估报告。

### 4.6 AI 智能咨询
1.  点击页面右下角的【AI 咨询】图标。
2.  在对话框中输入问题，例如：“专利申请流程是怎样的？”或“如何进行专利侵权判定？”。
3.  AI 助手将实时回复，并支持多轮对话。
4.  用户可对会话进行重命名或删除管理。

### 4.7 个人中心
1.  **我的专利**：管理已认领或上传的专利，支持编辑信息或发起转化申请。
2.  **我的需求**：查看已发布需求的匹配进度与对接状态。
3.  **账号设置**：修改登录密码，绑定手机号/邮箱，完善实名认证信息。

## 5. 常见问题 (FAQ)

**Q1: 忘记登录密码怎么办？**
A: 在登录页点击“忘记密码”，通过注册手机号接收验证码重置密码。

**Q2: 为什么搜索不到我的专利？**
A: 请确认专利号输入正确，或检查专利是否处于公开状态。如仍有问题，请联系客服。

**Q3: 发布的专利/需求审核需要多久？**
A: 通常在 1-3 个工作日内完成审核，结果将通过站内信通知。

**Q4: 平台收费吗？**
A: 基础检索与浏览功能免费。深度评估报告与专家对接服务可能涉及费用，具体请参考平台资费说明。
